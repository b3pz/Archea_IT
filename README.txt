ARCHEA SERVICE DESK V1.4

NOVITÀ
- USER normale: solo Apri ticket + I miei ticket + dettaglio/commenti/appuntamenti dei propri ticket.
- USER non vede Dashboard, Gestione IT, Movimenti, Prenotazioni, Censimento, checklist e note interne.
- IT: interfaccia completa.
- Appuntamenti dentro ogni ticket.
- Calendario appuntamenti IT.
- Quando IT fissa un appuntamento, il ticket passa a IN ATTESA.

INSTALLAZIONE
1. Supabase > SQL Editor: esegui migration_v1_4_appointments.sql una sola volta.
2. GitHub: sostituisci index.html, styles.css e app.js nella root.
3. Commit changes.
4. Attendi GitHub Pages e fai CTRL+F5.

PROSSIME FASI
- Telegram su nuovo ticket
- Email alla chiusura
- Checklist automatiche per categoria
- Movimenti collegati al gestionale HR con anti-duplicati
- Censimento
- Prenotazioni materiale + disponibilità + verbale firmabile/stampabile
